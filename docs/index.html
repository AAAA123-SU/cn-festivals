在苹果设备上添加

iOS 16 及以上版本路径一致
1

打开系统设置

设置 → 日历 → 账户 → 添加账户

2

选择「其他」

在账户类型列表底部选择 其他，再点 添加已订阅的日历。

3

粘贴订阅链接

服务器一栏粘贴上面的链接，点「下一步」；自动同步的日历建议把「移除提醒」保留为关闭。

4

调整刷新频率（可选）

设置 → 日历 → 账户 → 已订阅的日历 → 刷新日程，可选每 15 分钟至每周。

macOS 更快捷：日历 App →「文件」→「新建日历订阅」，粘贴链接即可。Outlook / Google 日历同样支持「通过网址添加」。

数据说明

节日日期怎么来的

  • 农历日期按 Meeus 天文算法计算的朔日与太阳视黄经推算，遵循《农历的编算和颁行》（GB/T 33661-2017）；
  • 清明、冬至按太阳到达对应黄经的时刻确定；
  • 与权威农历数据逐日比对，1929 年后完全一致，2100 年前均可直接推算。

假期与调休

    未收录的年度只列出《全国年节及纪念日放假办法》规定的法定天数，不推测调休日。

    会自动更新吗

    • 订阅源一次性覆盖多年，客户端定期拉取最新内容；
    • 节日日期由程序推算，任何时候拉取都是准确的；
    • 国务院公布新年度安排后，重新生成即可，已订阅的日历会自动同步。
    数据来源：国务院办公厅节假日安排通知 · 紫金山天文台历法规则
